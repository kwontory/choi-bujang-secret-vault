# 처음 실행하기 · 내 PC 타임라인 (한 장 안내)

이 안내만 보고 처음 보는 사람도 앱을 켤 수 있게 쓴 문서입니다. 위에서부터 차례로 따라 하세요. 막히면 맨 아래 표를 보고, 그래도 안 되면 **막힌 단계 번호와 화면의 오류 문구 전체**를 그대로 적어 알려 주세요.

앱이 하는 일: 이 PC의 CPU·메모리·디스크, 네트워크·방화벽·Windows 기록 건수를 **읽기만** 해서 조회한 시각 순서로 보여 줍니다. 설정을 바꾸지 않고, 관리자 권한도 필요 없습니다.

## 0. 준비물 (한 번만)

| 필요한 것 | 확인 방법 | 없으면 |
|---|---|---|
| Windows 10 또는 11 | — | 이 앱은 Windows용입니다. 다른 OS에서는 방화벽·기록 항목이 「확인 불가」로 나옵니다. |
| Node.js 22~24 (권장 **24.19.0**) | PowerShell에서 `node -v` → `v24.19.0` 처럼 나옴 | https://nodejs.org 에서 설치한 뒤 **PowerShell 창을 새로 엽니다**. |
| Git (저장소로 받을 때만) | `git --version` | https://git-scm.com 에서 설치하거나, GitHub에서 ZIP으로 받습니다. |

PowerShell 여는 법: 시작 메뉴에서 「PowerShell」을 검색해 엽니다. 관리자 권한으로 열 필요는 없습니다.

## 1. 프로젝트 받기

```
cd $HOME\Documents
git clone https://github.com/kwontory/choi-bujang-secret-vault.git
cd choi-bujang-secret-vault
```

- 저장소가 비공개라 받을 수 없으면 저장소 주인에게 접근 권한을 요청합니다.
- ZIP으로 받았다면 압축을 푼 폴더(`choi-bujang-secret-vault`)로 `cd` 합니다. 이후 안내의 「프로젝트 폴더」는 이 폴더입니다.

## 2. 내 PC 타임라인 켜기

```
cd pc-timeline
npm.cmd test
npm.cmd start
```

- `npm.cmd test` 마지막 줄 근처에 `# fail 0` 이 보이면 정상입니다.
- `npm.cmd start` 뒤에 `케셰브 PC 타임라인: http://127.0.0.1:5190` 이 나오면 켜진 것입니다. **이 창은 닫지 말고 둡니다.**
- `npm` 이 아니라 `npm.cmd` 를 쓰는 이유: PowerShell 보안 설정 때문에 `npm` 이 막히는 PC가 많습니다. 설정은 바꾸지 않습니다.
- 외부 패키지를 설치하지 않으므로 `npm install` 은 필요 없습니다.

## 3. 화면 열기

브라우저 주소창에 `http://127.0.0.1:5190` 을 입력합니다(`https` 아님).

정상이면: 맨 위에 「최근 조회 … · 조회 실패 0」이 보이고, 아래에 「CPU·메모리·디스크」, 「네트워크·방화벽·Windows 기록」, 「SDP 서버 연결」 기록 세 개가 쌓입니다. 「다시 조회」를 누를 때마다 맨 위에 새 기록이 생깁니다.

- 「SDP 서버 연결」은 케셰브 앱을 켜지 않았으면 「? 확인 불가」로 나옵니다. **정상입니다.** 보고 싶으면 4번을 따라 합니다.
- 「Windows 기록」의 오류·경고 건수는 「ℹ 참고」입니다. 침해나 공격을 뜻하지 않습니다.

## 4. (선택) 케셰브 앱도 켜서 SDP 연결 상태 보기

**새 PowerShell 창**을 하나 더 열고 프로젝트 폴더에서:

```
cd on-client
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -NoNativeHost
```

- `-NoNativeHost` 는 계정 연결 준비 없이 화면만 켜는 옵션입니다. 개인 설정 파일을 만들지 않습니다.
- `-ExecutionPolicy Bypass` 는 이번 실행에만 적용되며 PC 설정을 바꾸지 않습니다.
- 켜진 뒤 타임라인 화면에서 「다시 조회」를 누르면 「SDP 미연결」(ℹ 참고)로 바뀝니다. 실제 SDP 서버 연결은 담당자 설정이 있어야 하므로 「미연결」이 정상입니다.

## 5. 끄기와 다시 켜기

- 끄기: 앱을 켠 PowerShell 창에서 `Ctrl + C`.
- 다시 켜기: 프로젝트 폴더에서 2번(필요하면 4번)을 다시 합니다. 기록은 화면을 새로고침하면 지워집니다.

## 막혔을 때

| 화면에 나온 것 | 원인 | 할 일 |
|---|---|---|
| `'node' 용어가 … 인식되지 않습니다` | Node.js가 없거나 설치 뒤 창을 새로 열지 않음 | 0번대로 설치하고 **PowerShell 창을 새로 엽니다**. |
| `npm.ps1 파일을 로드할 수 없습니다` | PowerShell 실행 정책 | `npm` 대신 `npm.cmd` 를 씁니다. 그래도 막히면 `node --test`, `node server.mjs` 로 실행합니다. |
| `포트 5190를 이미 쓰고 있습니다` | 이미 켜 둔 창이 있음 | 다른 PowerShell 창을 확인해 `Ctrl + C` 로 끄거나, `$env:PC_TIMELINE_PORT=5191; npm.cmd start` 로 켜고 `http://127.0.0.1:5191` 을 엽니다. |
| `git` 을 인식하지 못함 | Git 미설치 | Git을 설치하거나 GitHub에서 ZIP으로 받습니다. |
| 브라우저에서 「사이트에 연결할 수 없음」 | 앱 창이 꺼져 있거나 주소 오타 | 2번 창이 켜져 있는지, 주소가 `http://127.0.0.1:5190` 인지 확인합니다. |
| 빨간 「일부 조회에 실패했습니다」 | 조회 중 앱 창이 꺼졌거나 오류 | 앱 창을 확인하고 「다시 조회」. 계속되면 기록의 오류 코드를 그대로 알려 주세요. |
| 방화벽·Windows 기록이 「? 확인 불가」 | PC 정책·권한으로 읽기가 막힘 | 정상 동작입니다(읽지 못한 값을 꾸미지 않음). 권한이나 보안 설정을 바꾸지 마세요. |
| SDP 서버 연결이 「? 확인 불가」 | 케셰브 앱이 꺼져 있음 | 4번을 따라 하거나 그대로 둡니다. |
