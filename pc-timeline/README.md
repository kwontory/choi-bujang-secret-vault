# 내 PC 타임라인 (케셰브 학생 앱)

케셰브 마지막 총공세에서 학생이 새로 만든 앱입니다. 이 PC의 상태를 **읽기만** 해서, 조회할 때마다 시각과 결과를 한 줄씩 위로 쌓아 보여 줍니다(기록 타임라인형). 제공 시작 틀(`on-client/`)의 파일은 고치지 않았습니다.

## 지금 보여 주는 것

「지금 조회」 한 번에 아래 세 묶음이 각각 한 줄(기록)씩 쌓입니다.

### ① CPU·메모리·디스크 (2일차)

| 항목 | 값 | 읽는 방법(일반 권한) |
|---|---|---|
| CPU 사용률 | % (0.5초 간격 두 번 측정한 평균) | Node.js `os.cpus()` |
| 메모리 사용량 | %, 사용 GB / 전체 GB | Node.js `os.totalmem()` · `os.freemem()` |
| 디스크 남은 공간 | %, 남은 GB / 전체 GB (시스템 드라이브, 보통 C:) | Node.js `fs.statfs()` |


### ② 네트워크·방화벽·Windows 기록 (3일차)

| 항목 | 값 | 읽는 방법(일반 권한, 읽기만) |
|---|---|---|
| 네트워크 연결 | 주소를 받은 어댑터 수, 어댑터별 주소 종류(사설·공인·자동 할당) | Node.js `os.networkInterfaces()` — IP 주소 자체는 화면에 내지 않음 |
| 방화벽 설정 | 프로필(Domain·Private·Public)별 켜짐·꺼짐 | PowerShell `Get-NetFirewallProfile` |
| Windows 기록 · System / Application | 최근 24시간 오류·경고 건수 | PowerShell `Get-WinEvent` (Level 2·3) |

- 방화벽과 보안 설정은 **읽기만** 하고 바꾸지 않습니다. 설정을 바꾸는 명령은 코드에 없습니다(자동 시험으로 확인).
- PowerShell은 셸을 거치지 않고 고정된 읽기 스크립트만 실행하며, 15초 안에 끝나지 않으면 멈추고 확인 불가로 둡니다.
- Windows 경고·오류 건수는 **침해나 공격 탐지 결과가 아닙니다.** 그래서 정상·주의 대신 「ℹ 참고」로 표시합니다.
- 권한 때문에 못 읽은 항목은 권한을 바꾸려 하지 않고 확인 불가와 이유로 남깁니다.

### ③ SDP 서버 연결 (3일차, PC 조회와 별도)

- 케셰브 앱(`127.0.0.1:5189`)의 `/api/me` 응답만 보고 「SDP 연결됨 / SDP 미연결 / 예제 모드」를 나눕니다.
- 케셰브 앱이 꺼져 있어 확인하지 못하면 미연결로 단정하지 않고 **확인 불가**와 이유를 보여 줍니다.
- 이 기록은 SDP 연결 상태일 뿐, 이 PC를 조회한 결과와 섞지 않으려고 따로 쌓습니다.

### 공통

- 값마다 **잰 시각**과 **출처**(화면에서 설명 위에 마우스를 올리면 보임)를 붙입니다.
- 값을 읽지 못하면 0이나 예시 값으로 채우지 않고 **확인 불가**와 이유를 보여 줍니다.
- **주의** 기준은 앱이 정한 것이며 침해 판정이 아닙니다: CPU 90% 이상, 메모리 90% 이상, 디스크 남은 공간 10% 미만.
- 화면에는 예시 값이 없습니다. 보이는 숫자는 모두 이 PC에서 방금 잰 실측 값입니다.
- 기록은 화면을 연 동안만 메모리에 두며, 새로고침하면 지워집니다.

## 실행

준비: Windows, Node.js 22~24(수업 기준 24.19.0). 외부 npm 패키지는 없습니다.

```
cd C:\Users\victo\work\choi-bujang-secret-vault\pc-timeline
npm.cmd test
npm.cmd start
```

PowerShell에서 `npm test` 가 「이 시스템에서 스크립트를 실행할 수 없으므로 npm.ps1 …」로 막히면 `npm.cmd` 를 쓰세요. PC 실행 정책은 바꾸지 않습니다. `node --test` 와 `node server.mjs` 로 직접 실행해도 같습니다.

브라우저에서 `http://127.0.0.1:5190` 을 엽니다. 끄려면 앱 창에서 `Ctrl + C` 를 누릅니다. 포트를 바꾸려면 `$env:PC_TIMELINE_PORT=5191; npm.cmd start` 처럼 실행합니다.

## 확인 순서

1. `npm.cmd test` 가 `pass 26`, `fail 0` 으로 끝나는지 봅니다.
2. 화면을 열면 첫 조회가 자동으로 실행되어 기록 세 줄이 생깁니다. 「지금 조회」를 누를 때마다 맨 위에 새 기록이 쌓입니다.
3. `Ctrl + Shift + Esc` → 작업 관리자 「성능」 탭과 비슷한 시각에 비교합니다. CPU는 순간값이라 몇 %씩 차이 날 수 있습니다. 값이 크게 다르면 잰 시각과 범위(디스크는 C: 하나만)를 먼저 확인합니다.
4. 거부되어야 할 것: `http://127.0.0.1:5190/api/anything` 은 404, 읽기 외 요청(POST)은 405, 다른 이름이나 다른 사이트에서 보낸 요청은 421·403 입니다(자동 시험에 포함).
5. 방화벽은 Windows 보안 → 「방화벽 및 네트워크 보호」 화면, 경고·오류 건수는 이벤트 뷰어(`eventvwr.msc`) → Windows 로그 → System·Application 의 「현재 로그 필터링」(지난 24시간, 오류·경고)과 비교합니다.
6. 케셰브 앱을 끄고 조회하면 SDP 항목이 「확인 불가」로, 켜면 「SDP 미연결」(현재 상태)로 나와야 합니다.
7. 앱 창을 끈 상태에서 「지금 조회」를 누르면 「조회 실패」 기록과 다음에 할 일이 보여야 합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `server.mjs` | 127.0.0.1:5190 에서만 열리는 서버. 화면 파일과 읽기 전용 주소 `GET /api/pc/system` · `/api/pc/connections` · `/api/sdp/status` 만 제공 |
| `probe/system.mjs` | CPU·메모리·디스크 측정. 실패 시 확인 불가와 이유 |
| `probe/network.mjs` | 네트워크 어댑터 연결 상태(주소 비공개) |
| `probe/windows.mjs` | 방화벽 설정·Windows 기록 건수 읽기(고정 PowerShell 스크립트) |
| `probe/sdp.mjs` | 케셰브 앱의 SDP 연결 상태 읽기 |
| `public/` | 타임라인 화면 (HTML 문자열을 쓰지 않고 글자만 넣음) |
| `test/` | 계산·확인 불가·서버 허용/거절 시험 |
