# 완성본 시연과 정리 · 내 PC 타임라인 (마지막 총공세 7일차)

작전: 화면 틀 **기록 타임라인형**, 포장 **포장 없이 프로젝트 폴더에서 실행**(설치 프로그램은 과정 뒤 참고). 이 문서는 확인한 것만 「확인함」으로 적고, 확인하지 않은 것은 「미확인」 또는 「미실시」로 남깁니다.

## 1. 제공 기능과 내가 만든 기능

| 구분 | 내용 | 위치 |
|---|---|---|
| 제공(시작 틀 0.2.14) | 케셰브 앱 서버·공통 화면·실행 도구, SDP·AI·조치·OSV 연결 틀 | `on-client/src/`, `on-client/public/`, `on-client/tools/` — 고치지 않음 |
| 내가 만든 것(13~22단계) | 케셰브 학생 표시 함수 8개, 실행 설명서 | `on-client/student/extension.mjs`, `on-client/docs/STUDENT_RUNBOOK.md` 등 |
| 내가 만든 것(마지막 총공세) | 내 PC 타임라인 앱 전체: 읽기 전용 측정, 서버, 타임라인 화면, 시험, 안내 | `pc-timeline/` |
| 내가 만든 것(마지막 총공세) | 케셰브 보호 현황에 「내 PC 타임라인 열기」 링크 | `on-client/student/extension.mjs` |

제공 시작 틀에는 사이트 안내에 나온 「내 PC 상태」 기능이 없었고(0.2.14 업데이트 뒤에도 없음), 학생 영역(`student/`)만으로는 PC 값을 케셰브 화면에 넣을 통로가 없었습니다(제공 화면의 허용 주소 6개 고정, `connect-src 'self'`). 그래서 제공 파일을 고치지 않고 별도 학생 앱(`127.0.0.1:5190`)을 만들었습니다.

## 2. 핵심 기능 3가지와 시연 순서

준비: PowerShell 창 두 개. ① `on-client` 에서 케셰브 켜기, ② `pc-timeline` 에서 `npm.cmd start`. 자세한 명령은 [QUICKSTART.md](QUICKSTART.md).

| 순서 | 기능 | 보여 줄 것 | 말할 것 |
|---|---|---|---|
| 1 | **CPU·메모리·디스크 실측** (2일차) | `http://127.0.0.1:5190` 첫 기록, 작업 관리자 「성능」 탭과 나란히 | 값마다 잰 시각·단위·출처(「자세히」). 못 읽으면 0이 아니라 「확인 불가」와 이유 |
| 2 | **네트워크·방화벽·Windows 기록 읽기** (3일차) | 두 번째 기록, 방화벽 「켜짐 3/3」, 기록 건수 「ℹ 참고」 | 읽기만 하고 설정은 바꾸지 않음. 건수는 침해 판정이 아님. SDP 연결 상태는 별도 기록 |
| 3 | **조회 기록 타임라인** (4일차) | 「다시 조회」로 기록 쌓기 → 거르기(주의·확인 불가·참고) → 키보드 `Tab`·`Enter` 로 조작 → 앱 창을 끄고 「다시 조회」 해 빨간 실패 안내 | 실패를 성공처럼 보이지 않게 하고 다음 행동을 안내. 실패 뒤 `npm.cmd start` 로 다시 켬 |
| 마무리 | 케셰브 보호 현황 맨 아래 링크 | 「내 PC 타임라인 열기」 | 두 앱은 따로 켜며, 케셰브 연결 상태와 PC 조회는 별개 |

## 4. 한계 (아직 안 되거나 확인 불가로 남은 것)

- **SDP 서버 미연결**: 케셰브의 로그인·업무 앱·보안 기록·기기·세션은 `ENGINE_NOT_CONNECTED` 로 실제 값이 없습니다(담당자 설정 필요). 타임라인은 이를 「SDP 미연결」로만 표시합니다.
- **AI 연결·설명(17·18단계)**: 이번 과정에서 계정 연결과 AI 승인을 다시 하지 않아 미확인입니다.
- **설치 패키지 OSV(20단계)**: `PROJECT_NOT_CONFIGURED`(담당자 설정 필요)로 조회되지 않습니다.
- **Windows 전용**: 방화벽·Windows 기록은 Windows에서만 읽습니다. 다른 OS에서는 「확인 불가」입니다.
- **기록 보관**: 타임라인 기록은 화면을 연 동안 메모리에만 있고 새로고침하면 지워집니다(최대 60건). 파일·DB에 남기지 않습니다.
- **측정 범위**: 디스크는 시스템 드라이브(C:) 하나만, CPU는 0.5초 순간 평균, Windows 기록은 최근 24시간 오류·경고 건수만 봅니다.
- **다른 사람의 첫 사용 관찰**: 미실시(도와줄 사람이 없었음). 안내는 자기 점검과 새 폴더 재현(Linux)으로만 보완했습니다.
- **두 앱 따로 실행**: 케셰브(5189)와 타임라인(5190)을 각각 켜야 합니다.
- **포장·설치 프로그램**: 이번 과정에서는 하지 않았습니다.
